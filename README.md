# North Home Solutions

Single-page website for North Home Solutions — a remodeling & finishes contractor serving
Destin, Santa Rosa Beach and Panama City, FL. Custom tile, showers, kitchen countertops,
flooring and general remodeling.

Static HTML/CSS/JS, no build step. Deploy folder: `site/`.

## Run locally

```bash
python3 -m http.server 8095 --directory site
# → http://localhost:8095
```
